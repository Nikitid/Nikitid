## Projects

### OpenWrt

- **[IKEv2 Site Link for OpenWrt](https://github.com/Nikitid/luci-app-ikev2-site-link)** (`luci-app-ikev2-site-link`) - LuCI application for a monitored, fail-closed IKEv2 link between two OpenWrt routers  `Shell`
- **[Overview Manager for OpenWrt](https://github.com/Nikitid/luci-app-overview-manager)** (`luci-app-overview-manager`) - LuCI application for ordering and hiding widgets on the OpenWrt Status Overview page  `Shell`
- **[Nikitid APK feed for OpenWrt](https://github.com/Nikitid/openwrt-feed)** (`openwrt-feed`) - Signed APK feed for Nikitid OpenWrt 25.12 LuCI applications.  `Shell`
- **[Wi-Fi QR for OpenWrt](https://github.com/Nikitid/luci-app-wrqr)** (`luci-app-wrqr`) - LuCI widget that shows a Wi-Fi QR code for each active access point on the Status Overview page.  `Shell`
- **[MTProto Monitor for OpenWrt](https://github.com/Nikitid/luci-app-mtproto-monitor)** (`luci-app-mtproto-monitor`) - LuCI application for monitoring local Telegram MTProto proxies and managing their WAN port exposure.  `Shell`
- **[IKEv2 Manager для OpenWrt](https://github.com/Nikitid/luci-app-ikev2-manager)** (`luci-app-ikev2-manager`) - LuCI application for IKEv2 tunnels and selective policy routing on OpenWrt.  `Shell`
